# Claude Project Guidance

This repository is already planned using a BMAD-style artifact chain. Do not restart discovery unless a requirement changes.

Use this reading order:
`START_HERE.md` -> `PROJECT_STATE.md` -> `_bmad/planning/*` -> relevant skill -> relevant story -> code.

When implementing:
- make the smallest coherent change,
- keep all service endpoints configurable,
- keep demo fallback behavior working,
- add/update tests,
- update the story and project state.
