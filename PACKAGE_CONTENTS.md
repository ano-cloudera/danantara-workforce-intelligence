- a functional custom frontend CAI Application,
- a FastAPI + CrewAI Flow backend with direct Google Gen AI SDK integration,
- a Qdrant CAI launcher,
- a local observability CAI Application with optional Langfuse forwarding,

- Cloudera AI deployment guidance,
- BMAD planning artifacts, epics and stories,
- coding-agent skills and project instructions,
- API/data contracts, security guidance and demo runbook,
- reference UI mockups and PoC architecture.
