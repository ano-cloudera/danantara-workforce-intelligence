# UX Specification

The UI is an enterprise HR application, not a generic chatbot.

Primary pages:
- Talent Intelligence: ranked candidate cards, score, matched skills, gaps, reasoning and human review label.
- Policy Intelligence: compare policies, AI summary, retrieved sources and citations.
- Data Sources: PDF upload, candidate registration form and pipeline status.
- Settings: non-secret model/data/guardrail settings and service health.
- Dashboard: link to Cloudera Data Visualization for management analytics.

Reference mockups are stored under `artifacts/ui/`.
