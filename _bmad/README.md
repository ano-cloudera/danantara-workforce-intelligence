# BMAD Artifact Chain

This project uses the BMAD pattern of **agentic planning + context-engineered development**.

Planning order:
1. Project Brief
2. BRD
3. PRD
4. Architecture
5. UX Specification
6. Risk Register
7. Epics and detailed stories
8. Project state handoff

The purpose is not to reproduce the BMAD framework itself, but to keep the repository ready for AI-assisted development without losing business and architecture context.

BMAD is not required for every repository change. Use
`skills/delivery-method-selector/SKILL.md` before planning work:

- direct implementation for small, bounded maintenance and fixes;
- lightweight spec-kit planning for medium, well-defined features;
- the BMAD artifact chain for material business, architecture, governance, or cross-platform work.

An existing BMAD story provides context but does not automatically make BMAD the required method.
